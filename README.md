# Zhengxin Shuzhi Technology - Enterprise Website

## Project Overview

This is a complete, production-ready corporate website for Shenyang Zhengxin Shuzhi Technology Co., Ltd, a leading provider of enterprise digital solutions including AI, IoT, and advanced software development.

**Website:** https://zhengxinshuzhitech.com  
**Company:** Shenyang Zhengxin Shuzhi Technology Co., Ltd  
**Location:** 812 (92), 8th Floor, No. 66 Shenfu Road, Shenyang, Liaoning 110000, China

## Key Features

### Website Pages
- **Homepage (index.html)** - Business overview, feature highlights, and value proposition
- **Services (services.html)** - Comprehensive service offerings and business capabilities
- **Company Culture (culture.html)** - Team values, culture, and employee experience
- **News & Updates (news.html)** - Latest announcements, product launches, and industry news
- **Contact (contact.html)** - Contact form, office information, and support channels
- **Mobile Apps (apps.html)** - Enterprise mobile applications for iOS and Android
- **Privacy Policy (privacy.html)** - Comprehensive privacy policy with GDPR, CCPA compliance
- **Terms of Service (terms.html)** - Complete terms and conditions

### Design & Development
- **Modern Responsive Design** - Mobile-first approach with full desktop support
- **Smooth Animations** - CSS3 animations and transitions for engaging user experience
- **Professional Styling** - Blue and orange color scheme inspired by enterprise brands
- **SEO Optimized** - Meta tags, structured data, and search engine friendly architecture
- **Performance Optimized** - Fast load times with optimized assets and caching

### Technical Stack
- **HTML5** - Semantic markup with accessibility best practices
- **CSS3** - Advanced styling with animations, gradients, and responsive design
- **Vanilla JavaScript** - Interactive features without heavy dependencies
- **SVG Icons** - Scalable vector graphics for logos and UI elements
- **Progressive Web App** - PWA manifest for installability

### Key Features Implemented
1. **Navigation Bar** - Sticky header with mobile menu toggle
2. **Hero Section** - Large hero banner with CTA buttons and feature cards
3. **Content Sections** - Grid-based layouts for various content types
4. **Contact Forms** - Client-side validation and form handling
5. **Scroll Animations** - Reveal animations on scroll using Intersection Observer
6. **Mobile Apps Integration** - Full section dedicated to mobile applications
7. **Advertisement Platform Integration** - Detailed info about AdMob and other ad networks
8. **Comprehensive Legal Pages** - Privacy policy and terms addressing:
   - GDPR compliance (EU users)
   - CCPA compliance (California users)
   - PIPEDA compliance (Canadian users)
   - Age restrictions and child privacy (COPPA)
   - Advertisement platforms (Google AdMob, Facebook, Amazon, etc.)
   - App store policies (Google Play, Apple App Store)
